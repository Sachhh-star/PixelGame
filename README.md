## 🎮 How to Download and Play

Follow these steps to play the game on your computer.

### Step 1: Download and install Godot

1. Go to the official Godot website: [https://godotengine.org/download](https://godotengine.org/download)
2. Download **Godot 4.6**.
   - ⚠️ **Important:** Use the same Godot version as the project. A different version might not open the project correctly.
3. Install or extract Godot on your computer.

### Step 2: Download the project

1. Open our GitHub repository: **[GITHUB REPOSITORY LINK]**
2. Click the green **Code** button.
3. Click **Download ZIP**.

### Step 3: Extract the ZIP file

1. Find the ZIP file you downloaded (usually in your **Downloads** folder).
2. Right-click it and choose **Extract All** (or use your favorite unzip tool).
3. Remember where you saved the extracted folder.

### Step 4: Import the project into Godot

1. Open **Godot**.
2. In the Project Manager, click **Import**.
3. Go to the extracted folder and select the **`project.godot`** file.
4. Click **Import** (or **Import & Edit**) to open the project.

### Step 5: Play the game

Click the **Run Project** button (▶️ in the top-right corner) or press **F5** to start playing.

Have fun! 🎉
